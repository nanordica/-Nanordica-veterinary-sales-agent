# Kontakti rikastamine

Olemas on ainult **e-posti aadress + kaasatuse staatus**. Muu (nimi, kliinik,
loomaliik, värske artikkel) tuleb juurde otsida. See fail kirjeldab kuidas.

## Mida koguda (andmemudel)

| Väli | Näide |
|------|-------|
| Eesnimi | Anna |
| Kliiniku nimi | Rīgas Veterinārā klīnika |
| **Konkreetne loomaliik / eriala** | kassid, koerad, hobused, veised, eksootilised |
| Regioon | Rīga, Liepāja, maapiirkond |
| Roll | omanik, praktiseeriv arst, ostujuht |

## Allikad

- **E-posti domeen** → kliiniku tuvastus (nt `@kliinikunimi.lv`).
- **Läti veterinaarregister** — Pārtikas un veterinārais dienests (PVD).
- **Latvijas Veterinārārstu biedrība** (kutseliit).
- **Kliiniku veebileht** (eriala, loomaliigid, meeskond).
- **Google / LinkedIn** avalik profiil.

## Värske sisu rikastamine (igale kirjale uus haak)

Iga jada-kiri vajab uut väärtust. Otsi kontaktile sobiv **hiljutine
teadusartikkel**, mis toetab RavimusVET-i tema kasutusjuhul:
- hobusearstile → hobuste krooniliste haavandite / haavaravi uuring,
- kassi-/koeraarstile → väikeloomade haavaravi, atraumaatiline sidemevahetus,
- veisearstile → suurloomade haavainfektsiooni / antimikroobse ravi uuring.

Lingi artikkel kirja kui uus väärtus. **Ainult päris, kontrollitud allikad —
mitte väljamõeldud viited.** Kui sobivat artiklit ei leia, kasuta mõnda muud
haaki (pakkumine, kasutusnäide).

## Fallback

Kui kontakti ei leia:
- kasuta ainult **käitumispõhist segmenti** ja üldist vetisõnumit,
- **ära genereeri** väljamõeldud (hallutsineeritud) andmeid,
- märgi kontakt **"rikastamata"**.
